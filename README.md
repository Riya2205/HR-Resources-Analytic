📊 HR Resources Analytics Dashboard

This project is an interactive **Power BI dashboard** created to analyze HR data and provide meaningful insights about an organization's workforce. It helps visualize important HR metrics such as employee count, salary distribution, department-wise performance, age groups, gender diversity, and employee attrition in one place.
The dashboard is designed to make HR reporting simple, interactive, and easy to understand, allowing users to explore data through filters and visualizations.

 📊 Key Features :-
- Displays important HR KPIs like Total Employees, Average Salary, Average Age, and Attrition Rate.
- Analyzes employee distribution across different departments.
- Visualizes gender diversity within the organization.
- Shows employee distribution based on different age groups.
- Provides salary analysis to understand compensation trends.
- Tracks employee performance using interactive charts.
- Highlights employee attrition to identify retention challenges.
- Includes interactive slicers and filters for better data exploration.
  
 🛠️ Tech Stack :-
- **Power BI** – Dashboard development and interactive visualizations
- **Power Query** – Data cleaning and transformation
- **DAX** – Creating calculated measures and KPIs

 🗂️ Dataset :-
The dashboard is built using an HR employee dataset containing information such as:
- Employee ID
- Department
- Job Role
- Gender
- Age
- Salary
- Performance Rating
- Years of Experience
- Education
- Marital Status
- Attrition Status

📈 Insights :-
Using this dashboard, users can:
- Understand the overall workforce composition.
- Compare employee distribution across departments.
- Identify salary trends among employees.
- Analyze gender and age diversity.
- Monitor employee performance.
- Track employee attrition and identify areas that need improvement.

🚀 How to Use :-
1. Download or clone this repository.
2. Open the Power BI file (`.pbit` or `.pbix`) in **Power BI Desktop**.
3. Load the dataset if required.
4. Refresh the data.
5. Explore the dashboard using the available filters and slicers.
   
💼 Business Value :-
This dashboard helps HR teams and management make better decisions by providing a clear overview of workforce data. It simplifies employee analysis, supports workforce planning, identifies attrition trends, and helps monitor employee performance through interactive visualizations.
